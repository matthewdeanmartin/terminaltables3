Coming from terminaltables?

terminaltables3 is a maintained fork of the archived terminaltables project, in a new namespace so the two never conflict. Replace terminaltables with terminaltables3 in your imports and you're done.

- from terminaltables import AsciiTable
+ from terminaltables3 import AsciiTable

FAQ

Which Python versions are supported?

Python 3.8 and newer, on Linux, macOS and Windows, including PyPy.

Does it have dependencies?

No runtime dependencies. Color libraries such as colorama or termcolor are optional and only needed if you use them in your cells.

Which style should I choose?

AsciiTable renders on any terminal. SingleTable and DoubleTable look nicer where box-drawing is available. Use the Markdown table to generate README tables and PorcelainTable for output that other programs parse.

Can I add a title?

Yes, for Ascii, Single and Double tables. Markdown and Porcelain tables have no top border, so titles are ignored there.

How do I report a bug or contribute?

Open an issue or pull request on GitHub. See CONTRIBUTING.md first.
